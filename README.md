# 💰 Money Mirror

> **Personal Finance Dashboard** — Take control of your money with a clean, intuitive web application.

---

## 📌 Overview

**Money Mirror** is a personal finance management web application that helps you track your income, expenses, and savings goals in one place. No more juggling between multiple bank apps or messy spreadsheets.

It provides a clear, visual snapshot of your financial health and helps you make smarter spending decisions.

---

## ✨ Key Features

### Current Features (MVP)
- 🔐 **Secure Authentication** — JWT-based login and registration
- 💳 **Multi-Account Management** — Track multiple accounts (cash, credit cards, savings)
- 📝 **Transaction Tracking** — Add, edit, and delete income and expenses
- 📂 **Predefined Categories** — Organize transactions by spending categories
- 📊 **Dashboard Overview** — See your total balance, income, and expenses at a glance
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile

### Upcoming Features
- 📈 **Advanced Analytics** — Charts, trends, and spending patterns
- 🎯 **Savings Goals** — Set and track financial goals with progress bars
- 📤 **Export Data** — Download your transaction history as CSV/PDF
- 🤖 **AI Predictions** — Smart forecasts based on your spending habits
- 🔄 **Bank Integration** — Automatic transaction import via Plaid/Belvo
- 🔔 **Smart Notifications** — Alerts for low balance, overspending, and bill reminders
